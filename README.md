## Accessibility Tools & Add-ons

### NVDA Synthesizers & Extensions
- **[eloquence_64](https://github.com/fastfinge/eloquence_64)** (fastfinge)
  - Eloquence synthesizer NVDA add-on compatible with 64-bit versions of NVDA
  
- **[NVDAItemChooser](https://github.com/doubletaponair/NVDAItemChooser)** (doubletaponair)
  - Item Chooser add-on for the NVDA screen reader — searchable navigation of accessible items in any window or web page (NVDA+I)

### Windows Accessibility Utilities
- **[accessible-sensor-readout](https://github.com/OnjLouis/accessible-sensor-readout)** (OnjLouis)
  - Accessible Windows sensor readout and FanControl frontend for screen-reader users
  
- **[midi-cleaner](https://github.com/OnjLouis/midi-cleaner)** (OnjLouis)
  - Accessible portable MIDI cleanup utility for Windows
  
- **[MoveToMidi](https://github.com/OnjLouis/MoveToMidi)** (OnjLouis)
  - Accessible portable Ableton Move and Note bundle to MIDI converter for Windows
  
- **[soundWave](https://github.com/OnjLouis/soundWave)** (OnjLouis)
  - Render text to WAV files through NVDA speech synthesizers

### Large Print & Reading Tools
- **[glow](https://github.com/Community-Access/glow)** (Community-Access)
  - ACB Large Print Toolkit — VS Code agents, Word document tool, and cross-platform CLI/GUI for American Council of the Blind Large Print Guidelines compliance
  
- **[newsFusion](https://github.com/OnjLouis/newsFusion)** (OnjLouis)
  - UK-focused news feed reader for NVDA

### Image & Content Tools
- **[Image-Description-Toolkit](https://github.com/kellylford/Image-Description-Toolkit)** (kellylford)
  - Experimental tools for image description interaction
